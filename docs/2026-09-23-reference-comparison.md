# NCG를 위한 글로벌 서비스 비교와 제안

조사일: 2026-09-23. 공식 제품 페이지·개발자 문서·발표 자료를 우선했다. 규모 수치는 각 운영사의 발표이며 누적 설치, 참여 교회, 제공 언어를 서로 다른 지표로 구분했다. 월간 활성 이용자 순위나 실측 성능 순위가 아니다. 두란노 QT와 BibleProject 홈페이지의 탐색 구조는 브라우저에서도 직접 확인했다.

## 추천 방향

NCG는 **예수 그리스도의 십자가와 부활을 중심으로, 세계의 사람들이 같은 말씀을 각자의 언어로 읽고 함께 살아가는 앱**으로 설계한다. 가장 가까운 참고 조합은 YouVersion의 성경 접근성, 두란노의 QT 흐름, BibleProject의 교육 구성, Church Online Platform의 예배 참여, Faith Comes By Hearing의 오디오 접근성이다.

특히 **전 세계 QT**를 매일 돌아오는 이유로 삼고, 예배·설교·새신자 교육을 그 여정에 연결하는 것을 권한다. 모든 기능을 홈에서 같은 크기로 나열하면 처음 온 사람이 시작점을 찾기 어렵다.

## 바로 개발에 도움이 되는 발견

**YouVersion Platform을 성경 본문의 첫 연동 후보로 검토한다.** 2025년 12월 공개 베타를 시작했고, 2026년 3월 31일 공식 발표에서 무료 플랫폼과 1,283개 언어·1,487개 성경을 안내했다. 이는 발표 당시 플랫폼 수치이며 Bible App 전체 목록과 같지 않다. 앱 등록, 키 발급, 해당 역본의 이용 동의, 출처 표기가 필요하다. 실제 NCG에서 사용할 수 있는 역본 목록은 등록 후 확인해야 한다. [공식 발표](https://www.youversion.com/news/introducing-youversion-platform), [개발자 문서](https://developers.youversion.com/api-usage).

**오디오와 소수 언어 보완 후보는 Bible Brain이다.** 텍스트·오디오·영상 목록을 언어와 국가별로 조회할 수 있고, 낮은 비트레이트 및 적응형 오디오 형식을 제공한다. 연결할 본문·오디오의 제공 범위와 사용 조건을 확인한 다음 적용한다. 두 공급원의 언어 수는 중복되므로 더해서 NCG 지원 수로 광고하지 않는다. [공식 API 안내](https://www.faithcomesbyhearing.com/bible-brain/developer-documentation).

두 서비스 모두 이번 작업에서 계정을 만들거나 이용 약관에 동의하지 않았고, API를 실제 연결하지 않았다.

## NCG의 화면과 이용 흐름 제안

하단 메뉴는 **홈 · 전 세계 QT · 말씀/예배 · 나눔 · 성경교육** 다섯 가지로 단순화한다. NCG School은 교육 영역의 브랜드이고, 안쪽 메뉴는 **새신자 교육 / 성경퀴즈 / 세례·입교 교육**처럼 뜻이 분명한 말을 쓴다.

홈 상단은 다음 순서로 구성한다.

1. **예수 그리스도의 십자가와 부활, 복음 알아보기** — 처음 온 사람이 신앙의 출발점을 찾는다.
2. **오늘 전 세계가 함께 읽는 말씀** — 본문, 내 언어로 읽기·듣기, 묵상 시작.
3. **예배와 말씀** — 진행 예정 예배와 실제 등록된 설교. 날짜·생방송 표시는 검증된 정보만 사용한다.
4. **이어 배우기** — 새신자 교육, 성경퀴즈, 개인 학습 진도.

전 세계 QT의 중심 흐름:

**공동본문 → 내 언어로 읽기/듣기 → 묵상 질문 → 오늘의 적용·기도 → 전 세계 나눔**

- 같은 `QT 발행 ID`를 중심으로 모든 언어의 본문·해설·나눔을 연결한다. 시간대에 따라 글이 서로 다른 모임으로 흩어지지 않게 한다. 공통 발행 시각과 각 사용자의 현지 날짜를 구분한다.
- 본문은 교회가 정한 읽기 계획에 따라 운영자가 검토·예약 발행한다. 현재 로컬 시안의 한 본문을 자동 일일 발행 서비스로 표현하지 않는다.
- 나눔 카드에는 요청대로 **이름·국적·원문 언어**를 표시하고, 본문은 열람자의 언어로 보여준다. 국적은 사용자가 직접 선택하며 언어나 현재 위치로 추정하지 않는다.
- **자동번역 / 교회 검수 번역 / 원문 보기**를 구분한다. 번역 실패 시 원문과 다른 지원 언어 선택을 제공하고 내용을 만들어내지 않는다.
- 개인 묵상은 기본 비공개로 저장하고, 공개 나눔을 별도로 선택하는 구조를 권한다. 댓글·기도 응답·신고·운영자 처리를 글로벌 공개 전에 연결한다.
- 공개 표시 이름은 본명 강제 인증 없이 사용할 수 있도록 권한다. 이름·국적·언어 공개 범위를 작성 전에 알린다.

## ‘모든 언어’의 구현 원칙

언어를 선택할 수 있는 것과 실제로 그 언어의 콘텐츠를 제공하는 것은 다르다. 지원 상태를 다음 네 층으로 관리한다.

| 층 | 제공 방식 | 품질 원칙 |
|---|---|---|
| 화면 메뉴 | 번역 문자열, 글꼴, 우→좌 언어 배치, 접근성 | 메뉴뿐 아니라 오류·안내·가입 흐름까지 검수 |
| 성경 본문 | 사용 허가된 해당 언어 역본 | AI가 생성한 번역을 정식 역본으로 대신하지 않음 |
| 설교·QT 해설·교육 | 교회 원고 → 번역 초안 → 언어별 검수·발행 | 핵심 신학 용어와 성경 인용 대조, 자막·원고 연결 |
| 사용자 나눔 | 요청 시 자동번역, 결과 캐시, 원문 유지 | 번역 표시, 실패 안내, 수정·삭제 시 캐시 갱신 |

현재 지원하지 않는 언어도 요청을 남기고 대체 오디오·공인 자료·언어 사역자에게 이어질 수 있게 설계한다. 전 세계 모든 언어를 이미 번역할 수 있다고 약속하지 않고, **접근할 길이 없는 언어를 확인하고 채워가는 운영 체계**를 갖춘다. 수어는 텍스트 자동번역만으로 해결할 수 없으므로 별도 영상과 검수가 필요하다.

## 속도와 비용 장벽을 낮추는 방식

- 기본은 YouTube 링크 등록과 누르기 전 플레이어 미로딩. 사용자가 눌렀을 때 재생한다.
- YouTube 접근이 어려운 환경을 위해 교회가 보유한 설교 원고·오디오·직접 호스팅 영상의 대체 경로를 마련한다. YouTube 영상의 무단 다운로드를 전제로 하지 않는다.
- 무료 열람, 회원가입 없이 복음·본문·설교·교육 보기. 계정은 기기 간 진도와 나눔 작성에 사용한다.
- 데이터 절약 모드, 영상 자동재생 끄기, 오디오·텍스트 선택, 허가된 콘텐츠의 오프라인 저장을 제공한다.
- 후원은 콘텐츠 이용 조건과 분리한다. 번역·저장·전송 비용은 교회 운영 예산과 후원 구조 안에서 관리한다.

## 개발 순서 제안

1. **전 세계 QT의 실제 연결**: 역본 공급원·언어별 사용 가능 범위 확인, 교회 편집·발행 기능, 계정과 공유 DB, 글 번역·원문 보기, 신고·관리 기능.
2. **예배와 교육 연결**: 새빛교회 공식 YouTube 채널, 자막·원고, 다바르에서 선별한 새신자·세례·입교 12개 수업과 퀴즈를 교회 검수 후 제공.
3. **접근 범위 확장**: 저속 통신 실측, 음성·오프라인, 언어별 검수 협력, 오른쪽에서 왼쪽으로 읽는 언어, 수어, 앱 배포.

1차 성공 기준은 회원 수보다 **선택한 언어로 실제 본문을 열 수 있는지, QT에서 나눔으로 이어지는지, 번역 실패에도 원문을 읽을 수 있는지, 느린 통신에서도 기본 내용을 볼 수 있는지**로 잡는다. 통계는 개인정보를 최소화하여 집계한다.

## 소속과 콘텐츠 운영

NCG의 운영 주체는 **대한예수교장로회(합동) 경기동중노회 소속 새빛교회**다. 자체 제작한 앱·원고에는 새빛교회 저작권을 명시한다. 연동 성경 역본·외부 영상에는 각각의 제공자와 요구되는 출처를 함께 표시한다. 참고 서비스의 인터페이스 패턴을 배우는 것과 해당 서비스의 원고·영상·디자인 자산을 복제하는 것은 구분한다.

이 문서의 구성·우선순위·운영 원칙은 조사 결과를 바탕으로 한 **NCG를 위한 제안**이다. 타 서비스에서 동일한 글로벌 번역 QT 기능을 제공한다고 주장하는 문서가 아니다.

## 추가 기준: 갓피플성경

사용자가 가장 편리하게 사용했다고 지정한 [갓피플성경](https://gpbible.godpeople.com/)을 성경 찾기/읽기의 주요 참고로 추가한다. 이 URL에서 확인한 것은 앱 소개와 기능 안내이며, 실제 웹 본문 리더를 조작한 것으로 표현하지 않는다. 공식 안내는 묵상노트·읽기 계획·그룹 읽기·말씀 알림·다양한 읽기 설정을 함께 제공한다. 일부 역본에는 별도 이용 조건이 있으므로 NCG의 무료 접근 목표에 맞는 정식 공급 계약을 별도로 마련한다.

NCG 반영: 책/장/절 이동, 원문 언어와 역본 선택, 글자 크기·읽기 배경·책갈피·이전/다음 장을 같은 화면에 모은다. 읽던 위치와 개인 설정을 유지하고 PC/휴대전화에서 동일한 순서로 찾는다. 모바일 최종 메뉴는 홈·성경·QT·나눔·성경교육으로 갱신했다. School은 새신자/세례/입교/심화 총28과, 소요리문답107문답, 게임형 성경퀴즈까지 확장했다.
