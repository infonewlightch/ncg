NCG는 새빛교회(대한예수교장로회 합동, 경기동중노회)의 무료 복음 전도·성경교육 웹앱임을 설명했습니다. 언어·국적·경제적 형편과 관계없이 말씀을 접하도록 하는 목적, 로그인 없는 무료 성경 열람, 계정이 필요한 공동체 기능을 구분했습니다.

최신 영어 NIV 신·구약 전체를 PC·모바일 웹/PWA 안에서 원문 그대로 열람하도록 허가를 요청했습니다. 무료 선교 사용을 위한 무상 라이선스, 감면 또는 사역 협력 가능 여부를 정중히 문의했고, 비용 약정은 하지 않았습니다.

앱에 AI를 활용한 화면·나눔 번역과 영어 WEB 기반의 참고 번역 기능이 있음을 명확히 밝혔습니다. NIV의 AI 학습·자동 재번역·개작은 요청하지 않으며, 원문 열람/검색/QT 등과 분리하는 방식이 허용되는지 별도 검토를 요청했습니다. 무료 앱이라는 이유만으로 Express License 적용을 가정하지 않았습니다.

현재 서비스는 개발 미리보기이고 확립된 이용자 기반을 가진 완성 제품이 아니며, NIV 전문을 복제하지 않았음을 밝혔습니다. 정식 신청 전에 예비 안내가 가능한지 문의했습니다.
