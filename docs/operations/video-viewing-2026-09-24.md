# 설교 시청 개선 · 2026-09-24

- 일반 화면의 개인 영상 등록 기능과 기기 영상 목록 표시를 제거했습니다. 홈·설교·보관 목록에는 서버에서 공개한 영상만 사용하며, 기존 기기 저장 데이터 자체는 삭제하지 않습니다.
- 영상 등록은 별도 관리자 화면과 관리자 전용 저장 RPC에만 남았습니다. 일반 회원·비회원의 직접 쓰기 거부 SQL 테스트가 통과했습니다.
- 설명은 원본 개행과 빈 문단을 `pre-wrap`으로 표시합니다. 현재 공개 설교의 원본에 개행이 저장돼 있음을 관리자 화면에서 확인했습니다.
- 사용자가 알려준 한국어·영어·스페인어·포르투갈어·중국어·힌디어·아랍어·페르시아어·태국어의 더빙/자막을 현재 공개 영상 `4YFNv1Szab8`에 등록했습니다. migration 012를 001–011 적용 여부 확인 후 단일 트랜잭션으로 실행했고, 해당 영상 오디오 9 / 자막 9 결과를 확인했습니다.
- 제목/설명 자동 번역은 공개 영상 ID만 받으며, 매 요청에서 공개 상태를 다시 확인한 후 소스 내용·대상 언어 기준으로 캐시합니다. 원문이 수정되면 새 번역을 생성합니다. 줄 단위 ID로 번역한 뒤 원래의 빈 줄과 개행을 재구성합니다. 임의 텍스트 전송·비공개 영상·불완전 응답을 차단하고 일일 생성 예산을 적용합니다.
- 임베드 자막은 `cc_lang_pref` / `cc_load_policy`로 요청하며, 오디오 트랙은 유튜브 설정에서 선택하도록 안내합니다. URL 파라미터가 오디오를 강제로 바꾼다고 표시하지 않습니다. [YouTube 공식 매개변수](https://developers.google.com/youtube/player_parameters), [오디오 언어 선택 도움말](https://support.google.com/youtube/answer/13339776?hl=en).
- 관리자 로그인은 이메일·비밀번호 방식으로 분리했습니다. 비밀번호 초기 설정/재설정과 로그인 후 본인 비밀번호 변경 화면을 제공합니다. 로그인 성공과 관리자 권한 부여는 별개이며 `ncg_is_admin` 서버 검증을 유지합니다. 실제 비밀번호 입력·저장은 사용자가 수행합니다.
