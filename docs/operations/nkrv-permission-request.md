# 개역개정 웹앱 이용허가 문의 초안

작성: 2026-09-24 · 상태: **발송 전 / 허가 미취득**

수신: 대한성서공회 저작권 담당, kbscopyright@bskorea.or.kr
제목: 새빛교회 NCG 무료 다국어 웹앱의 개역개정 성경 이용허가 문의

안녕하세요. 대한예수교장로회(합동) 경기동중노회 소속 새빛교회에서 운영하는 NCG 개발 담당입니다.

NCG는 세계 각지의 이용자가 자신의 언어로 성경을 읽고, 같은 본문으로 QT를 나누며, 신앙 기초와 성경을 배울 수 있도록 준비하는 서비스입니다. 한국어 성경에는 개역개정을 제공하고자 하며, 정식 사용허가와 본문 공급 방법을 문의드립니다.

- 운영 주체: 새빛교회
- 소재지: 대한민국 경기도 광명시 하안동 200-1, 4층
- 공식 연락처: infonewlightch@gmail.com
- 서비스 이름: NCG - New Light Church Global
- 주소: https://newlightchurchglobal.com/
- 이용 방식: PC·모바일 웹 및 설치형 PWA. 현재 앱스토어 배포 전.
- 대상과 비용: 전 세계 이용자, 성경·QT·교육 열람에 이용료를 받지 않는 방향.
- 요청 역본: 성경전서 개역개정판, 신·구약 전체.
- 계획 기능: 책·장·절 열람, 검색, 장절 선택·책갈피, 동일 단락을 활용한 일일 QT, 글자 크기 조절. 오프라인 저장과 구절 공유는 허가 범위에 맞춰 제한할 수 있습니다.
- 현재 상태: NCG 안에는 개역개정 본문을 복제하여 제공하지 않으며, 대한성서공회 공식 성경 읽기 페이지로 연결합니다.

다음 사항을 안내해 주시면 감사하겠습니다.

1. 무료 교회 웹앱·PWA와 QT 본문 제공에 적용되는 계약 유형, 연간 사용료, 갱신 조건
2. 공식 본문 파일 또는 API 공급 여부와 승인된 공급자 이용 방법
3. 검색·캐시·기기 오프라인 저장·구절 공유의 허용 범위 및 인용 분량
4. 저작권 표기 문구, 원문 교정본 업데이트 절차, 이용 통계 제출 여부
5. 전 세계 접속과 다국어 UI에서 한국어 개역개정 본문을 열람하는 경우의 지역 제한
6. 신청서·교회 확인 자료·화면 견본 등 제출이 필요한 서류

NCG의 별도 영어 기반 자동 참고 번역은 개역개정의 번역·수정본으로 표시하거나 제작하지 않겠습니다. 개역개정은 승인된 원문 그대로, 안내해 주시는 허가 조건을 따라 제공하고자 합니다.

감사합니다.
