# NCG 운영 서버

현재 로컬 구현입니다. 원격 배포, 공급자 연결, 실제 계정·비용 검증은 아직 하지 않았습니다.

## 실행

Node.js 24 LTS 환경에서 프로젝트 루트의 `.env.local`을 설정하고 실행합니다.

```sh
npm install
npm test
npm run build
npm start
```

기본 주소는 `http://127.0.0.1:4311`입니다. 개발 서버4310과 저장공간이 다른 로컬 운영 빌드입니다. `npm run preview`는 배포용 서버가 아닙니다.

운영 시에는 실제 HTTPS 도메인을 `NCG_PUBLIC_ORIGIN`으로 지정하고 TLS 프록시 뒤에서 실행합니다. 기본 bind는 loopback입니다. 프록시가 Host를 공개 도메인으로 전달해야 합니다. `NCG_TRUST_LOOPBACK_PROXY=1`은 loopback 프록시가 사용자의 X-Forwarded-For를 **덮어써서** 전달하는 경우에만 설정합니다.

`VITE_` 환경변수는 빌드에 포함되는 공개 설정입니다. Supabase URL·publishable/anon 키·VAPID 공개키만 허용합니다. 번역키, 성경 공급자키, Supabase 서비스키, VAPID 비밀키는 클라이언트에 넣지 않습니다. 웹 서버의 번역 인증/본문 열람은 서비스키가 아니라 사용자 토큰과 RLS를 사용합니다.

## API와 보안 경계

- `/api/bible/*`: 사용허가 받은 YouVersion 카탈로그·본문. 서버키, 고정 공급자 호스트, HTTPS, 타임아웃, 원문 그대로 반환, 본문 no-store. 실제 키가 없으면 연결 전 오류.
- `/api/translate`: 공개 글은 ID로 RLS를 통과한 서버 원문을 조회한 뒤 번역합니다. 방문자가 요청 본문을 바꿔 임의 텍스트를 번역할 수 없습니다. 공개되지 않은 글은 작성자/허용된 관리자 권한을 따릅니다.
- 개인 텍스트/대화 번역은 Supabase `getUser`와 활동제한 여부를 확인합니다. 원문과 번역을 공개 로그에 쓰지 않습니다. 외부 번역 공급자 사용은 운영 개인정보 안내에 반드시 반영해야 합니다.
- 번역 캐시는 메모리15분/300항목. 개인 내용은 사용자별 영역, 공개 글은 글ID별 영역. 요청은12KB/본문1800자, 공급자 응답4096토큰 제한·20초 타임아웃·동시3개. 잘린 결과나 미지원 표시를 번역으로 게시하지 않습니다.
- 요청180회/분/IP, 번역30회/분 및300회/일/사용자 또는 익명IP, 서버 전체 기본3000회/일. **한 인스턴스의 메모리 제한**이며 재시작 시 초기화됩니다. 다중 인스턴스 전에는 공유 제한 저장소를 도입하고 공급자 계정에도 예산 한도를 설정합니다. 캐시 응답도 요청 한도에 포함합니다.
- 지정 Host/Origin만 허용합니다. 외부 페이지가 API를 사용하도록 CORS를 개방하지 않습니다.
- 정적 파일은 dist 내부 실제 경로만 읽고 숨김 파일·경로 이탈·심볼릭 링크 이탈을 막습니다. HTML/SW는 no-store, 해시 자산은 immutable. `/admin.html`은 noindex이며 화면 숨김과 별도로 서버 관리자 권한을 검사합니다.
- CSP, nosniff, frame-ancestors, referrer policy를 적용합니다. 폰트·YouTube·Supabase 등 현재 필요한 출처만 허용합니다.

## 검증과 운영 전 확인

로컬 테스트는 토큰 검증/실제 공개 원문/비공개 거부/할당량/위조 IP/정적 경로/CSP/압축/UTF-8 경계/번역 캐시 격리를 검사합니다. 실제 공급자와는 통신하지 않습니다. HTTPS 배포 전에는 실제 Google·이메일 복귀 주소, RLS 사용자2명, 제공자 비용/이용약관, 기기별 푸시 수신, 장애 복구를 확인해야 합니다.

클라이언트 빌드를 갱신할 때 열려 있던 이전 버전의 해시 자산도 기존 세션이 끝날 때까지 제공하는 원자적 릴리스 방식을 사용합니다. 개발 중 dist만 교체하면 열린 페이지의 늦은 import가404가 될 수 있으며 새로고침이 필요합니다.
