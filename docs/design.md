# NCG 화면과 콘텐츠 기준

## 중심

예수 그리스도의 십자가와 부활을 중심에 둔다. 말씀 읽기·교육·나눔의 핵심 접근에 비용이나 국적 제한을 두지 않는다. 구현되어 있지 않은 언어/번역/회원/알림/공유를 구현된 것처럼 표시하지 않는다.

## 시각 체계

교회가 제공한 남색(#123564) 바탕의 금색 십자가/지평선 심볼을 대표로 사용한다. 원본 PDF에서 추출한 심볼은 public/brand에 있다. 화면은 밝은 바탕·흰 카드·남색 주 행동·금색 작은 강조를 사용한다. 녹색 계열의 별도 페이지 테마를 만들지 않는다. 정답/오류에는 의미 색을 별도로 쓴다.

공통 색상은 styles.css의 첫 :root에서 관리한다. 본문을 읽을 때는 줄길이와 행간을 충분히 확보한다. 작은 휴대전화에서는 콘텐츠가 한 열로 흐르며 하단 메뉴 높이만큼 여백을 둔다. 퀴즈 진행 중에는 소개 영역을 축소해 질문과 선택지에 공간을 준다.

## 언어

사용자가 고르는 language 하나가 메뉴와 콘텐츠의 선호 언어다. ui는 준비된 번역에 맞춰 도출한다. 한국어/영어는 메뉴부터 안내까지 같이 바뀐다. 다른 언어는 선택을 유지하면서 영어 UI 대체 안내를 표시한다. 교육은 ko/en/th 원문이 있으며 지역 태그는 기본 언어에 대응한다. 향후 번역 카탈로그를 더할 때 공통 resolver와 실제 제공 상태를 함께 갱신한다.

언어 선택 목록, 실제 번역된 UI, 콘텐츠 번역, 정식 성경 역본의 이용 가능 범위는 다른 정보다. 성경 본문은 기계번역으로 대체하지 않는다. 사용자의 나눔 번역은 원문 확인 수단과 자동번역 표시를 제공한다. 국적과 사용 언어를 동일하게 추정하지 않는다.

## 화면 구성

PC: 홈, 전 세계 QT, 성경 읽기, 예배, 설교, 공동체, 친구/대화, 성경교육. 마이페이지는 계정 진입점이다.

모바일: 홈 · 성경 · QT · 나눔 · 성경교육. 예배/설교는 홈의 바로가기와 검색으로, 친구/대화는 공동체와 마이페이지에서 접근한다.

NCG School: 입문(새신자), 성장(세례/입교), 심화(제자양육16과), 소요리문답107문답, 성경퀴즈. 각 영역의 학습량을 섞어 잘못된 진도율을 표시하지 않는다.

성경: 갓피플성경을 탐색 편의성의 주요 참고로 삼는다. 실제 NCG 화면은 독자적으로 만든다. 책→장→절, 장 전체 읽기, 역본 선택, 읽기 설정, 이전/다음 장, 책갈피와 출처를 한 흐름으로 연결한다. 공개 소개 사이트에서 확인한 기능과 직접 조작한 기능을 구분한다.

QT: 하나의 공통 발행 ID와 같은 장절 범위를 모든 언어에 공유한다. 하루 소제목 단락 하나를 원칙으로, 긴 단락은 의미에 맞게 나누고 부분 번호를 보인다. 주간 일정, 개인 현지 시각 알림, 말씀 읽기→묵상→기도→나눔이 핵심이다. 주간 일정·관리자 초안/발행·시간대별 알림 코드를 구현했다. 현재 화면의 요한복음 주간안은 검수 전 미리보기이고, 실제 발행 서버와 푸시 발송은 연결 전이다.

## 신뢰와 운영

관리자는 일반 서비스 메뉴에 표시하지 않는다. 별도 admin.html에서도 서버 권한을 다시 확인한다. 보류·신고·차단 상태를 서버에서 강제한다. 없는 영상, 시청자 수, 나눔 수, 번역 수 또는 알림 성공을 만들어 표시하지 않는다.
